# 用語集

BPE 文書で使う用語の定義集です。
初心者は先に [具体例](walkthrough_ja.md) を読み、分からない言葉が出たらここを見てください。

学習導線: [learn_ja.md](learn_ja.md)

---

## A〜C

### AC
8x8 ブロックのうち、**DC 以外の係数**（親・子・孫）。細かい変化を表す。

### adjust_output
レート制限で復号が途中停止したとき、未確定係数を不確定区間の中点へ寄せる処理。復号側のみ。

### BPE（Bit Plane Encoder）
ビットプレーン単位で係数を送る圧縮方式（および本リポジトリの実装）。

### ビットプレーン
**整数係数の振幅** `|v|` を 2 進数で見たときの各ビット位。
重いビットから軽いビットへ順に送る。
IEEE 754 浮動小数のビット列ではない。

## D〜H

### DC
8x8 ブロック左上の係数（LL3）。その場所の **大まかな明るさ**。

### DPCM
隣接値との **差分** を取る方式。DC では `shifted_dc` の差を非負整数へ写像してから Rice する。

### DWT（離散ウェーブレット変換）
画像を **低周波（大まかな形）** と **高周波（細かい差）** に分解する変換。
BPE は 3 レベル固定。

### ガッグル（gaggle）
最大 16 ブロックを 1 束にした単位。Rice の `k` やオプションを共有する。

英語の gaggle は本来「ガチョウの群れ」を意味する普通の単語で、
CCSDS 122.0 では「係数の小さな群れ」という意味で使われています。
社名 Google（数学用語 googol＝10の100乗 に由来）と音が似ていますが、**語源も意味も無関係**です。

### HL / LH / HH / LL
DWT のサブバンド。
- **LL**: 低周波（近似）
- **HL**: 横方向の高周波
- **LH**: 縦方向の高周波
- **HH**: 斜めの高周波
数字（LL3 等）はレベルを表す。

## I〜R

### 有意（significant） / 無意
現在プレーンで、係数振幅のそのビットが 1 かどうか。
初めて有意になったときに符号(+/-)も送る。

### k（Rice パラメータ）
Golomb-Rice で、値を商と余りに分けるときの余りビット数。
`k` が大きいほど大きな値に有利、小さいほど小さい値に有利。

### 量子化（q）
DC を右シフトして低位を落とすこと。`q` がそのビット数。

### リファイン（refine）
すでに有意だった係数について、現在プレーンの 0/1 を追加して精度を上げること。

### エントロピー符号化（entropy coding）
情報理論のエントロピー H（平均ビット数の下限）に近づける符号化の総称。
BPE では Rice / Golomb-Rice が該当する。物理の「乱雑さ」とは別概念。
詳しくは [entropy_coding_ja.md](entropy_coding_ja.md)。

### Rice 符号
小さい非負整数を短く符号化する方法。
BPE には (A) AC シンボル用固定表と (B) DC 用の `k` 付き Golomb-Rice の 2 種がある。

## S〜Z / 日本語

### セグメント
画像を割った **符号化の処理単位**。ヘッダ + DC + AC が 1 セット。

### シンボル
ブロック走査が作る「今回送る情報」の切り出し（TypeP, TranB, TypeCi 等）。

### ステージ（gaggles1/2/3 + refine）
シンボルを種類ごとに Rice 出力する 4 パス。
1=TypeP, 2=TranB/D/Ci, 3=TranGi/Hi/Hij, 4=refine。

### TypeP / TranB / TranD / TypeCi / TranGi / TranHi / TypeHij
走査シンボルの種類。
- **TypeP**: 親の有意性
- **TranB**: 子孫のどこかに有意があるか（0 なら枝刈り）
- **TranD**: バンドごとの子孫への遷移
- **TypeCi**: 子 2x2 の個別
- **TranGi / TranHi**: 孫領域への遷移
- **TypeHij**: 孫の個別

### パディング
幅・高さを 8 の倍数にするため、端を埋めること。

### 親 / 子 / 孫
8x8 内の階層。レベル3が親、レベル2が子、レベル1が孫。
親が無意なら子孫も無意に近い、という仮定で枝刈りする。

### リフティング / 9/7
DWT の実現形式。9/7 はフィルタのタップ数の通称。
`-t 1`=整数可逆、`-t 0`=浮動小数（丸めあり）。

### rate_reached / segment_full
レート上限またはセグメントバイト上限に達した危陣のフラグ。

### regroup / degroup
サブバンド配置と 8x8 ブロック配置の並べ替え（および逆）。
